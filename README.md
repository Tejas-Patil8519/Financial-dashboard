# Financial Dashboard

## Files
- `finance.csv`: sample learning dataset (synthetic).
- `main.py`: Python data analysis.
- `analysis.sql`: equivalent starter SQL query.
- `output/`: created automatically when you run the Python file.

## Run
1. Install Python 3.10+.
2. Open a terminal in this folder.
3. Install packages: `pip install -r requirements.txt` (or use the shared requirements file).
4. Run: `python main.py`

Import the CSV into Power BI Desktop to create cards, bar charts, line charts, and slicers. See the shared Power BI guide in the all-project bundle.
